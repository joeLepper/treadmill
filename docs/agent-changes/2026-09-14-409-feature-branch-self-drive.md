- [#409](https://github.com/joeLepper/treadmill/pull/409) — ADR-0115 (amends ADR-0110): feature-branch teams SELF-DRIVE integration. In `merge_target=feature-branch` mode the coordinator (`tools/team-templates/coordinator/CLAUDE.md.tmpl`) (1) routes PR-open (§6.1) straight to §8 peer review — `task.ci_result` is informational (§3.5 gates only in `main` mode); CI runs on the human branch→main PR, not per finding — and (2) resolves `depends_on` INLINE at §9.3 after its own git merge+push, dispatching now-unblocked dependents itself rather than waiting on the `github.pr_merged` event/§3.3. So feature-branch mode never depends on the observer→coordinator event push (both CI-wake and pr_merged-wake). Main-merge mode is unchanged. Motivated by the first collaborator-repo dogfood (`netlify/agent-runner-orchestrator`, ADR-0113): CI-per-finding is slow/low-value, §3.5 mis-rolls-up skipped/multi-suite conclusions, and the event-push wake did not fire (the coordinator stalled on a correctly-synthesized ci_result). Conformance foil: `test_feature_branch_self_drives_no_ci_gate_inline_depends_on`.
