- **[#PR] Messaging library — ported ramjac-events invariant tests (task f6db308b, plan 6791c1cd, ADR-0093)**: adds `services/api/tests/test_messaging_invariants.py` — 10 tests ported from ramjac-events to harden the existing `treadmill_api/messaging/` package. Two load-bearing foils proven RED-then-GREEN: (1) `_MarkThenProcessCrashingConsumer` shows the mark-then-process bug (commit before handle) silently loses a message after a mid-handler crash — the broken variant's handler runs 0 times; the correct `MessageConsumer` redelivers and runs exactly once. Plus 6 claim/commit/expiry unit tests (fresh-key grants, in-window CLAIMED_ELSEWHERE, post-commit DUPLICATE, crash-window expiry reclaimable, terminal commit, independent consumer-id isolation). All ported units carry ramjac-events provenance comments.
