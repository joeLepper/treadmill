- [#407](https://github.com/joeLepper/treadmill/pull/407) — ADR-0113 PR-state poll reconciler for webhookless (collaborator-only) repos. New `POST /api/v1/github/poll-ingest` (merge leg) + `/poll-ingest/check-run` (CI leg) synthesize `github.pr_merged` / `github.check_run_completed` through the shared `persist_and_resolve_webhook_event` seam so a repo with no App/webhook still resolves merges + CI. Idempotent via a deterministic event_id existence-gate (the seam publishes unconditionally on ON-CONFLICT, so a re-poll must skip it); CI dedup keyed on `(check_suite_id, head_sha, conclusion)`. The CI leg writes `task_prs.head_sha` (keyed on the required `pr_number`) before the seam — on a webhookless repo nothing else populates it, so the `ci_observer` would otherwise fail to attribute. New `GET /api/v1/task_prs?repo=&open=` is the poll set. CLI `treadmill pr poll <repo> --account <acct>` (fail-closed on any `gh` non-zero, per-repo flock, `gh auth token --user`, never `gh auth switch`) + timer units `tools/cc-channels/systemd/treadmill-pr-poll@.{service,timer}` (not auto-enabled). Co-signed by Ernie. End-to-end dogfood pending (the treadmill stack is down).
