- **[#PR] Host placement — default-local, directed, fail-closed (task 12242df6, ADR-0100)**:
  adds `treadmill_api/placement.py` — `place_agent(session, label, store, *, directed_host,
  starter_host, bound_by) -> PlacementResult`. Default (no directed_host): binds to
  `starter_host` (or `TREADMILL_HOST` env var) via ADR-0095's `HostRegistryStore.bind_label`.
  Directed: checks the named host exists in `list_hosts` AND has a non-NULL `tailnet_addr`
  (reachable) before binding; refuses fail-closed on either failure — `PlacementResult(
  success=False, reason=<why>)`, no binding written, never rerouted. No scheduler,
  allocator, or reconciler — placement is set once at start. `PlacementResult` is a frozen
  dataclass: `success`, `host`, `reason`. No new migrations — writes existing
  `session_host_bindings` via the existing `HostRegistryStore`. Tests: 16 behavioral tests
  in `test_placement.py` covering DEFAULT (starter_host param, TREADMILL_HOST env, bound_by
  forwarded), DIRECTED (registered+reachable binds that host, does not bind to starter_host),
  FAIL-CLOSED (unregistered → refused, reason surfaces host name, no bind written;
  unreachable → refused, no bind written, no alternative host bound), FAIL-CLOSED FOIL
  red-then-green (red: naive code reroutes to starter_host on unregistered AND unreachable;
  green: real code refuses with no binding on both), and STARTER HOST ENV (ValueError when
  TREADMILL_HOST absent or empty). ADR-0098 static falsifier: 4 tests in
  `test_no_reroute_placement.py` — `test_no_reroute_placement` scans the repo for banned
  identifiers (`auto_reroute`, `reroute_on_load`, `relocate_on_load`, `fallback_placement`,
  `load_balance_placement`, `rebalance_placement`, `redirect_placement`) and for co-occurrence
  of load-trigger phrases (`overloaded`, `load_exceeded`, `at_capacity`, `host_load`,
  `load_threshold`, `capacity_exceeded`) + reroute-action phrases (`reroute`, `redirect`,
  `fallback`) in executable function bodies (docstrings stripped, same as ADR-0095 adoption
  guard). Meta-tests: Check-1 non-vacuity (plants `auto_reroute` → scan flags it), Check-2
  non-vacuity (`overloaded` + `redirect` flagged), and Check-2 negative (fail-closed
  refusal code with `unreachable` + no load trigger is NOT flagged — consistent with
  ADR-0100 §Risks: "a refusal is not a reroute").
