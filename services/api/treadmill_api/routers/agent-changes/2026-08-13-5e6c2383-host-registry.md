# 2026-08-13 — Host registry and per-label host binding endpoints (ADR-0095)

PR: [#373](https://github.com/joeLepper/treadmill/pull/373) — task 5e6c2383

Added `hosts.py` — a new APIRouter exposing six endpoints under `/api/v1/hosts`
and `/api/v1/hosts/bindings` for the ADR-0095 host registry:

- `POST /api/v1/hosts` — register or refresh a host (with optional `tailnet_addr`)
- `GET /api/v1/hosts` — list all registered hosts
- `POST /api/v1/hosts/bindings` — bind a label to a host (explicit-only)
- `GET /api/v1/hosts/bindings/{label}` — get bound host for a label; 404 if unbound
- `GET /api/v1/hosts/{host}/labels` — list all labels bound to a host
- `DELETE /api/v1/hosts/bindings/{label}` — remove a label binding; 204 or 404

The router is registered in `app.py`. Backing store is `host_registry_store.py`;
ORM models are in `models/host.py`.
